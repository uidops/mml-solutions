# Exercise 2.1 — An Abelian Group

> [!question] Problem
> **2.1** We consider $(\mathbb{R} \setminus \{-1\}, \star)$, where
>
> $$a \star b := ab + a + b, \quad a, b \in \mathbb{R} \setminus \{-1\} \tag{2.134}$$
>
> a. Show that $(\mathbb{R} \setminus \{-1\}, \star)$ is an Abelian group.
> b. Solve
>
> $$3 \star x \star x = 15$$
>
> in the Abelian group $(\mathbb{R} \setminus \{-1\}, \star)$, where $\star$ is defined in (2.134).

## Solution

> [!success] (a) — $(\mathbb{R} \setminus \{-1\}, \star)$ is an Abelian group
> **Closure:** For $a, b \in \mathbb{R} \setminus \{-1\}$,
>
> $$a \star b + 1 = ab + a + b + 1 = (a+1)(b+1).$$
>
> Since $a \neq -1$ and $b \neq -1$, we have $a+1 \neq 0$ and $b+1 \neq 0$, hence $(a+1)(b+1) \neq 0$. Therefore $a \star b + 1 \neq 0$, i.e. $a \star b \neq -1$, so
>
> $$a \star b \in \mathbb{R} \setminus \{-1\}.$$
>
> Thus $\mathbb{R} \setminus \{-1\}$ is closed under $\star$, and we may record the identity
>
> $$(a \star b) + 1 = (a+1)(b+1) \quad \text{for all } a, b \in \mathbb{R} \setminus \{-1\}, \tag{$\ast$}$$
>
> which holds for every product under $\star$. $\blacksquare$
>
> **Associativity:** For $a, b, c \in \mathbb{R} \setminus \{-1\}$,
>
> $$(a \star b) \star c = (ab + a + b) \star c$$
>
> $$= (ab + a + b)c + (ab + a + b) + c$$
>
> $$= abc + ac + bc + ab + a + b + c$$
>
> $$= a(bc + b + c) + a + (bc + b + c)$$
>
> $$= a \star (b \star c).$$
>
> $\blacksquare$
> 
> **Identity:** The element $e = 0 \in \mathbb{R} \setminus \{-1\}$ serves all $a \in \mathbb{R} \setminus \{-1\}$:
>
> $$e \star a = ea + e + a = 0 \cdot a + 0 + a = a,$$
>
> $$a \star e = ae + a + e = a \cdot 0 + a + 0 = a.$$
>
> Therefore $e = 0$ is the identity element of $(\mathbb{R} \setminus \{-1\}, \star)$. $\blacksquare$
>
> **Inverses:** For all $a \in \mathbb{R} \setminus \{-1\}$, we must find $a^{-1} \in \mathbb{R} \setminus \{-1\}$ with $a \star a^{-1} = a^{-1} \star a = e = 0$. Expanding and factoring the requirement
>
> $$a \star a^{-1} = aa^{-1} + a + a^{-1} = a^{-1}(a+1) + a = 0$$
>
> gives $a^{-1}(a+1) = -a$, and since $a \neq -1$ we may divide by $a+1$:
>
> $$a^{-1} = \dfrac{-a}{a+1}.$$
>
> This candidate lies in $\mathbb{R} \setminus \{-1\}$: the division is allowed because $a+1 \neq 0$, and $a^{-1} = -1$ would give $-a = -(a+1)$, a contradiction. Substituting back,
>
> $$a \star a^{-1} = a \cdot \dfrac{-a}{a+1} + a + \dfrac{-a}{a+1} = \dfrac{-a^2 + a(a+1) - a}{a+1} = \dfrac{0}{a+1} = 0 = e,$$
>
> and $a^{-1} \star a = a^{-1}a + a^{-1} + a$ expands to the same terms, hence is also $0 = e$. Therefore every element of $(\mathbb{R} \setminus \{-1\}, \star)$ has an inverse in $\mathbb{R} \setminus \{-1\}$. $\blacksquare$
>
> **Commutativity:** For $a, b \in \mathbb{R} \setminus \{-1\}$,
>
> $$a \star b = ab + a + b$$
>
> $$= ba + b + a \qquad \text{(multiplication and addition in } \mathbb{R} \text{ are commutative)}$$
>
> $$= b \star a.$$
>
> Therefore $\star$ is commutative, and $(\mathbb{R} \setminus \{-1\}, \star)$ is closed, associative, has an identity and an inverse for every element — an Abelian group. $\blacksquare$

> [!success] (b)
> By associativity (a), $3 \star x \star x = 3 \star (x \star x)$, so $3 \star (x \star x) = 15$. Starring both sides with $3^{-1}$ — by (a), $3^{-1} = \dfrac{-3}{4}$ — gives
>
> $$3^{-1} \star \bigl(3 \star (x \star x)\bigr) = 3^{-1} \star 15 \quad \Longrightarrow \quad x \star x = \dfrac{-3}{4} \cdot 15 + \dfrac{-3}{4} + 15 = 3.$$
>
> Expanding $x \star x = x^2 + 2x$, we need $x^2 + 2x = 3$, i.e.
>
> $$x^2 + 2x - 3 = 0 \quad \Longleftrightarrow \quad (x-1)(x+3) = 0,$$
>
> so $x = 1$ or $x = -3$. Both lie in $\mathbb{R} \setminus \{-1\}$, and substituting back verifies them:
>
> $$3 \star 1 \star 1 = 7 \star 1 = 15 \qquad \text{and} \qquad 3 \star (-3) \star (-3) = (-9) \star (-3) = 15.$$
>
> Hence $x \in \{1, -3\}$. $\blacksquare$
