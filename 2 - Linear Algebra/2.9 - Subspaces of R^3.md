# Exercise 2.9 — Subspaces of $\mathbb{R}^3$

> [!question] Problem
> **2.9** Which of the following sets are subspaces of $\mathbb{R}^3$?
>
> a. $A = \{(\lambda, \lambda + \mu^3, \lambda - \mu^3) \mid \lambda, \mu \in \mathbb{R}\}$
>
> b. $B = \{(\lambda^2, -\lambda^2, 0) \mid \lambda \in \mathbb{R}\}$
>
> c. Let $\gamma$ be in $\mathbb{R}$.  
> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$C = \{(\xi_1, \xi_2, \xi_3) \in \mathbb{R}^3 \mid \xi_1 - 2\xi_2 + 3\xi_3 = 7\}$
>
> d. $D = \{(\xi_1, \xi_2, \xi_3) \in \mathbb{R}^3 \mid \xi_1 \in \mathbb{Z}\}$

## Solution

> [!success] (a) — $A$ is a subspace of $\mathbb{R}^3$
>
> The map $\mu \mapsto \mu^3$ is a bijection $\mathbb{R} \to \mathbb{R}$, so $A = \{(\lambda, \lambda + u, \lambda - u) \mid \lambda, u \in \mathbb{R}\}$, the image of the linear map $(\lambda, u) \mapsto (\lambda, \lambda + u, \lambda - u)$. Equivalently, all three axioms hold: $0 \in A$ (take $\lambda = u = 0$); the sum of $(\lambda_1, \lambda_1 + u_1, \lambda_1 - u_1)$ and $(\lambda_2, \lambda_2 + u_2, \lambda_2 - u_2)$ is $(\lambda_1 + \lambda_2,\, (\lambda_1 + \lambda_2) + (u_1 + u_2),\, (\lambda_1 + \lambda_2) - (u_1 + u_2)) \in A$; and scalar multiples are preserved in the same way. $\blacksquare$

> [!error] (b) — $B$ is not a subspace of $\mathbb{R}^3$
>
> $B$ contains $(1, -1, 0)$ (take $\lambda = 1$), but not its negative: $-(1, -1, 0) = (-1, 1, 0)$ would require $\lambda^2 = -1$, impossible for $\lambda \in \mathbb{R}$. Hence $B$ is not closed under scalar multiplication. $\blacksquare$

> [!error] (c) — $C$ is not a subspace of $\mathbb{R}^3$
>
> $C$ is an affine hyperplane that does not pass through the origin: $(0, 0, 0)$ gives $0 - 0 + 0 = 0 \neq 7$, so $0 \notin C$. $\blacksquare$

> [!error] (d) — $D$ is not a subspace of $\mathbb{R}^3$
>
> $D$ contains $(1, 0, 0)$ since $1 \in \mathbb{Z}$, but not $\tfrac{1}{2}(1, 0, 0) = (\tfrac{1}{2}, 0, 0)$, since $\tfrac{1}{2} \notin \mathbb{Z}$. Hence $D$ is not closed under scalar multiplication. $\blacksquare$
